# Sprint 5 - Análise de Anúncios de Vendas de Carros

Este projeto consiste no desenvolvimento de uma aplicação web interativa utilizando **Streamlit**, destinada a analisar dados de anúncios de vendas de veículos nos Estados Unidos.

## Funcionalidades da Aplicação
- Visualização de histogramas da distribuição de preços e quilometragem.
- Gráficos de dispersão comparando o preço em função do ano do modelo e quilometragem.
- Filtros dinâmicos e interativos integrados com Pandas e Plotly.

## Estrutura do Repositório
- `app.py`: Código principal da aplicação Streamlit.
- `vehicles_us.csv`: Base de dados utilizada para as análises.
- `requirements.txt`: Dependências do projeto.
- `notebooks/EDA.ipynb`: Jupyter Notebook contendo a Análise Exploratória de Dados inicial.
- `.streamlit/config.toml`: Configurações de tema da aplicação.
